# Drova: Forsaken Kin — русский перевод

Неофициальный фанатский перевод игры. Переведено с немецкого оригинала, английская версия использовалась для сверки.

Два варианта, отличаются репликами и журналом героя:

- `male/ru` — герой;
- `female/ru` — героиня.

Проверено на Steam-сборке игры 22911289.

## Установка

1. Steam → правой кнопкой по игре → «Управление» → «Просмотреть локальные файлы».
2. Перейти в `Drova_Data/StreamingAssets/Localization`.
3. Если там уже есть папка `ru` — сохранить её копию и удалить.
4. Скопировать в `Localization` папку `ru` из `male` или `female`.
5. В настройках игры выбрать русский язык.

Чтобы сменить вариант, повторите шаги 3–4 с другой папкой. Сохранения от этого не зависят.

Обновление игры или проверка целостности файлов в Steam может откатить перевод — тогда установите его заново.
